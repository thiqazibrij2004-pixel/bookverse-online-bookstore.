# BookVerse screenshots

45 actual Chrome PNG captures covering all 38 JSP files.

Open index.html for the module gallery, or open individual PNG files in the module folders. Desktop width: 1440 px; normal pages are full-page captures and dialogs are viewport captures. Shared header/footer are captured as components. Screenshots were taken against a separate Tomcat instance with a copy of the live data, plus generated screenshot-only customer/order/review records. No live data was changed.

The legacy Update Order JSP is included in its actual standalone state; the normal admin status workflow is shown separately in the Update Order Status modal. The Add Review capture shows its guest form because customers who already reviewed a book are redirected by the application.

Modules: Home, Books, Account, Cart, Wishlist, Orders/Payment, Reviews, Admin, Shared components.

See manifest.json for the exact source JSP and URL of each image. No passwords or authentication cookies are included.
